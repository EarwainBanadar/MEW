## Delivery order

Development packages are executed in numerical order unless an explicit architecture decision changes the sequence. A package may contain multiple batches, but it is considered complete only after all of its batches and acceptance criteria are verified.

## Status vocabulary

- Proposed
- Planned
- In progress
- Implemented
- Verified
- Released

Only the status needed for active work shall be maintained; MEW deliberately avoids a separate reporting bureaucracy.
