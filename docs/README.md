# MEW Project Documentation

This directory contains the persistent product, architecture, roadmap and decision documentation for the Manufacturing Engineering Workbench (MEW).

MEW is developed pragmatically: as much structure as necessary, as little process as possible.

## Structure

- `vision/` — product purpose and scope
- `architecture/` — target architecture and guiding principles
- `roadmap/` — development packages, batches and milestones
- `adr/` — essential architecture decisions only

GitHub is the single source of truth for code and project documentation.
