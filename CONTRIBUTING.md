# Contributing

1. Branch von `main` erstellen.
2. Änderungen mit Tests implementieren.
3. `pytest` lokal ausführen.
4. Dokumentation und Changelog aktualisieren.
5. Pull Request mit nachvollziehbarer Begründung erstellen.

Rule-IDs und öffentliche Datenmodelle dürfen nicht stillschweigend geändert werden.
Breaking Changes erfordern eine Major-Version.
